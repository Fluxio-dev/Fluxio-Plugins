# Fluxio Plugins

Plugin repository for **Fluxio** — a modern Tauri-based video streaming application. This repository contains scraper and metadata plugins used to fetch streaming resources from various sources.


## Plugin Architecture

Fluxio plugins are self-contained client-side modules that integrate with the main application runtime. They handle metadata resolution (querying catalogs, details, seasons, and episodes) and stream extraction (resolving source URLs for video playback).

### Template

A new plugin is defined by creating a folder with the following structure:

```
plugin-name
├── plugin.json   # Configuration metadata
└── plugin.js     # JavaScript runtime code
```
